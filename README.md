# Retail Sales Performance Dashboard

This Power BI dashboard analyzes retail sales performance across regions, product categories, and time trends.

## Key Insights
- Identified top-performing product categories and regions
- Tracked revenue and profit trends over time
- Visualized sales distribution across different segments

## Tools Used
- Power BI
- Power Query
- Data Visualization
